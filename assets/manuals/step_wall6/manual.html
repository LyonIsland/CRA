PIPER · ASSEMBLY MANUAL 01

六块积木 · 三层交错小墙

固定目标结构，积木可散落在不同位置。每一步都先找料，再对齐和连接。

准备材料

红色 2×4 ×1蓝色 2×4 ×1绿色 2×4 ×1黄色 2×4 ×1橙色 2×4 ×1紫色 2×4 ×1

另需一块夹紧且已标定的底板，至少覆盖 12×2 凸点，建议使用 16×16 或更大底板。长边沿 X 方向，所有积木凸点朝上。

这是项目生成的说明书。当前软件的规划、视觉与物理插接必须分别验收；摆到目标附近不等于已经卡接。

AGENT EXECUTION CONTRACT

给机器人 Agent 的执行规则

  1. 说明书提供目标结构、砖型、颜色、方向及依赖；不提供散落积木位置。
  2. 使用当前视觉观察搜索和选择积木，避免重复占用同一块。
  3. 底板未标定、缺料、遮挡或置信度不足时，停止并重新观察。
  4. 抓取、转向、限力压入和连接验收由独立技能执行。
  5. 只有实际连接证据满足本步骤的连接关系，才能推进步骤。仅看到位置接近不能确认完成。

机器可读版本：recipe.json。当前 Agent 读取这份结构化版本，不声称能直接理解任意外部 PDF。

现有 Windows 实心积木模型尚无经过验证的 LEGO 插接；执行器必须报告能力未就绪，不能自动把积木焊在一起后宣称完成。
